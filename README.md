# Clock Web

即時顯示日期與時間的網頁，採用深色玻璃質感設計，支援即時每秒更新。

## 功能特色

- **即時時鐘** — 每秒自動更新，精確顯示時:分:秒
- **日期顯示** — 顯示完整的年/月/日與星期
- **環形進度條** — 隨秒數推進的紫色視覺效果
- **AM / PM 標示** — 上下午提示
- **響應式設計** — 支援桌面與手機瀏覽
- **深色玻璃質感** — 現代化毛玻璃 UI 設計
- **呼吸光暈** — 背景漸層光暈動畫效果

## 技術架構

| 技術 | 用途 |
|------|------|
| HTML5 | 頁面結構 |
| CSS3 | 樣式、動畫、響應式 |
| JavaScript | 即時時鐘邏輯 |
| Google Fonts | JetBrains Mono + Outfit 字體 |
| GitHub Pages | 部署托管 |
